# 验收标准

本目录回答“交付必须满足什么”和“如何证明满足”。

- [产品需求与验收要求](REQUIREMENTS.md)：当前产品行为、范围和最终交付要求。
- [首个里程碑合同](milestone-1.md)：7 个实施切片、每片验收条件和完成定义。
- [测试与验收规格](TESTING.md)：测试分层、信息隔离负向矩阵、假模型场景和验收清单。
- [交付验收证据](EVIDENCE.md)：默认自动化、E2E、真实模型、浏览器验证与当前环境边界的可提交摘要。

实施进度请看[任务台账](../tasks/TASKS.md)；系统如何实现请看[工程规格](../spec/README.md)。本目录只写标准，不写完成流水。
