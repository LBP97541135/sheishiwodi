# 任务与 Checklist

本目录是实施进度的持久化事实源，避免任务只存在于单次 Claude 会话。

- [完整任务台账](TASKS.md)：TASK-000 起的全部任务、状态、依赖、目标、验收依据和证据。
- [首个里程碑 Checklist](milestone-1-checklist.md)：按切片与子任务展开的可勾选检查点。

## 状态定义

- `待办`：已登记但尚未开始。
- `进行中`：当前正在实施，必须有未完成检查点。
- `已完成`：实现和验收证据齐全。
- `阻塞`：存在无法自行解除的外部决策或依赖。

## 维护规则

1. 创建会话任务前先登记文档任务；临时发现的子任务也必须补入台账。
2. 每个任务开始前说明目标，并同步状态。
3. 每个检查点完成后立即勾选，不在切片结束时批量补写。
4. 测试失败、浏览器未验收或已知阻塞未解决时不得标记完成。
5. 已完成结果同步写入[开发记录](../history/PROJECT_LOG.md)，但规格文件不记录完成流水。
